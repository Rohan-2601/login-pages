# Next.js Login Starter

This project was initialized with Next.js, TypeScript, Tailwind CSS, ESLint, and the App Router.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Routes

- `/` welcome screen with a button linking to login.
- `/login` responsive login UI with email and password fields.

## Scripts

- `npm run dev` start local development.
- `npm run build` create a production build.
- `npm run start` run the production build.
- `npm run lint` run lint checks.

## Debug Or Launch

To debug in VS Code, start the app with `npm run dev` and attach a browser debugger to `http://localhost:3000`.

## Notes

The login page currently includes UI only. Connect the form submit flow to your auth backend when ready.
